# weblab-protocol

웹 디자인 훈련 자동화 시스템의 **작업 규격**입니다.

이 레포는 **공개**입니다. AI(Claude, Codex, Gemini, Grok 등)가 인증 없이 URL로
바로 읽을 수 있어야 하기 때문입니다. 실제 산출물은 별도 비공개 레포에 쌓입니다.

## AI에게 이 규격을 물릴 때

CLI 도구(Claude Code, Codex CLI)는 작업 레포의 `CLAUDE.md` / `AGENTS.md`가
자동으로 여기를 가리킵니다. 브라우저 AI에는 아래 링크를 그대로 던지면 됩니다.

- 작업 규격: https://raw.githubusercontent.com/dinored960018/weblab-protocol/main/PROTOCOL.md
- 용어 사전: https://raw.githubusercontent.com/dinored960018/weblab-protocol/main/GLOSSARY.md
- 완료 판정: https://raw.githubusercontent.com/dinored960018/weblab-protocol/main/CHECKLIST.md

## 파일

| 파일 | 내용 |
|---|---|
| `PROTOCOL.md` | ★ 단일 원본. AI가 따라야 할 작업 절차 전부 |
| `GLOSSARY.md` | 용어 사전. 시스템 용어 + 웹 용어(매주 자람) |
| `CHECKLIST.md` | CLONE/BUILD 완료 판정 기준 |
| `templates/` | SPEC / REVIEW / NOTES / CONCEPTS 템플릿 |
